# Glass Artist Portfolio

A minimal, elegant landing page for a contemporary glass artist. Built with Next.js 14 and Tailwind CSS.

## Design

- **Style**: Gallery-like, minimal, nude tones, thin typography
- **Colors**: Warm white (#F8F6F2), light beige (#EAE4DC), soft sand (#D8CFC4)
- **Typography**: Cormorant Garamond (serif), Inter (sans-serif)

## Sections

1. Hero – Full-screen cinematic intro
2. About – Artist portrait and biography
3. Featured Works – Filterable gallery (Sculptures, Installations, Exhibitions, Limited Editions)
4. Process – Three-step storytelling (Sketch → Shaping → Final)
5. Exhibitions & Press
6. Studio – Atmospheric quote overlay
7. Contact – Minimal form with commission option
8. Footer

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customization

- Replace placeholder images in each component with your artwork
- Update "Artist Name" in Header, Hero, and Footer
- Add your email, Instagram, and studio address in Contact
- Update exhibition list in Exhibitions component

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Responsive, mobile-first design
